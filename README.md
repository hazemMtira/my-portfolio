# Hazem Mtira portfolio

```
index.html          page content
css/style.css       all styling (colors are variables at the top)
js/hero.js          animated hero background (plain canvas, no libraries)
js/main.js          footer year + scroll reveal
Assets/             CVs (PDF) and favicon
```

**Deploy on Netlify:** open your site > Deploys > drag this whole folder into the drop area.

**Replace a CV:** overwrite the PDF in `Assets/` and keep the same file name.

**Add the Awqat repo link:** in `index.html`, find the comment inside the Awqat card and paste your URL.
